# Willowmere showcase media

This folder is the self-contained browser review surface for the Willowmere handoff. Open [the viewer](viewer/index.html) for the animated overworld, Lantern Ford camera panel, character playback, reduced-motion still, and keyboard controls. The exact editable projects and rebuild commands are in [`/examples/willowmere/README.md`](/examples/willowmere/README.md).

Named media files are stable guide references:

- `hero-overworld.png` and `hero-sideview-with-characters.png` are the two presentation stills.
- `character-comparison.png`, `character-contact-mira.png`, and `character-contact-reedling.png` document the redesign.
- `environment-stage-overworld.png` and `tutorial-preview.png` are stage and tutorial references.
- `overworld-showcase.mp4` is an optional 12-second publication clip.

All viewer animation behavior is page-side review code. PixelWall remains the source of the editable pixels, layers, frames, clips, and PNG exports.
