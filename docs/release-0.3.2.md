# PixelWall 0.3.2

Desktop updates can now download and install inside PixelWall.

- Download updates in the app with progress, cancellation, and retry.
- Choose **Restart to update** when ready, or **Later** to keep editing.
- PixelWall saves your artwork before restarting. A failed save postpones the update and keeps your work open.
- Downloaded updates are checked against the published release checksums before installation.
- Release notes and update controls are available from **Check for Updates…** in the PixelWall menu on Mac or Help on Windows and Linux.
- Automatic update checks can still be disabled. Updates do not install on an ordinary app quit.

If you are using 0.3.1 or earlier, install 0.3.2 once using the download for your computer. Future releases can then be installed inside PixelWall. On Mac, keep PixelWall in Applications; on Linux, keep the AppImage in a writable folder. Your existing artwork, preferences, and Pro license remain on your device.
