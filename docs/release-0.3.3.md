# PixelWall 0.3.3

A smoother workspace for projects with more layers and open tabs.

- More tooltips explain editor controls and layer settings.
- Float panels, then lock them back with Dock left or Dock right.
- Long layer lists have their own scrollbar, with a visible Delete layer button. Undo restores deleted layers.
- Project tabs have scroll controls and close buttons. Reopen saved projects from All projects.

From PixelWall 0.3.2, choose Check for Updates, download the update, then Restart to update. PixelWall saves your artwork first.
