# PixelWall 0.4.0

Animated water and isometric drawing tools in both the web editor and desktop app.

- Generate ponds, rivers, streams, waterfalls, and shorelines with a live preview. Choose top-down or isometric view.
- Keep the shoreline fixed while changing the water seed, ripple density, or animation phase. Seasonal palettes include frozen pond edges in winter.
- Edit the generated Banks, Water, Rocks, and Grass & Reeds layers. Generation saves the current project and opens a new project tab.
- Draw with a 2:1 isometric guide and snapping, or stamp editable tiles, raised blocks, and ramps.
- Follow the new water and isometric guides, with command examples and downloadable editable projects for people and agents.

Water animation loops in time. Automatic seamless connections between neighboring terrain or river tiles are not included. Generated scenes support 8–256 pixels per edge and 1–32 frames.

Individual PNGs and editable project exports remain free. Animated GIFs, sprite sheets, and game packages retain the existing Pro requirements.

In PixelWall 0.3.2 or later, choose Check for Updates, download the update, then Restart to update. PixelWall saves your artwork before restarting.
